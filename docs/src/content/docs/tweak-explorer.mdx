See what each tweak changes before you run it. Open a tweak to see the registry values and service startup types it sets next to what **Undo** restores, along with any script it runs. Search also matches registry paths, service names, and script contents, so you can find every tweak that touches a given setting.

The list is loaded from the latest WinUtil release on GitHub, the same version `https://christitus.com/win` runs.

<TweakExplorer client:load />

A tweak marked **Script has no undo** or **AppX removal has no undo** is one that Undo cannot fully reverse. Some are one-off actions with nothing to put back, such as creating a restore point or cleaning up temporary files. For the rest, create a restore point before applying them.
